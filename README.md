## What is TabCost?

TabCost calculates a small cost for each minute a browser tab stays idle (after a grace period), based on your professional hourly rate. It's a metaphor for your attention — not a real bill.

**Use cases:**

- **Distraction awareness:** Whitelist your work domains (Notion, Figma, Gmail, etc.) so only non‑productive tabs count.
- **Freelance context:** Visualize time spent on web tools — useful for internal reflection or as a reference for fixed‑price projects.
