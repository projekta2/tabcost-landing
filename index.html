How it works

  • 1. Install and set your hourly rate (e.g., $50/h).
  • 2. TabCost watches your tabs – only inactive tabs count (default grace: 5 min).
  • 3. See the cost accumulate in the popup. Each idle tab adds a small amount per minute.
  • 4. Upgrade to Pro to ignore work domains, auto‑close tabs, see 365‑day history, and more.

Why don't I see cost immediately? The extension has a 5‑minute grace period (adjustable in Pro). A tab must be inactive for longer than that to start generating cost. This prevents counting short pauses like checking a message or a quick browser switch.

Cómo funciona

  • 1. Instala y define tu tarifa por hora (ej. 50€/h).
  • 2. TabCost vigila tus pestañas – solo las inactivas cuentan (gracia: 5 min).

  • 4. Actualiza a Pro para ignorar dominios de trabajo, cierre automático, historial de 365 días y más.

¿Por qué no veo coste inmediatamente? La extensión tiene un período de gracia de 5 minutos (ajustable en Pro). Una pestaña debe estar inactiva más de ese tiempo para empezar a generar coste. Así evitamos contar pausas cortas como contestar un mensaje o cambiar de aplicación.
